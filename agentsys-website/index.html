The bottleneck isn't code generation.

Frontier models write good code. That's solved. What's not solved is context management, compaction amnesia, task drift, skipped steps, token waste, and babysitting.

  • Context management — models forget what they're doing mid-session.
  • Compaction amnesia — long sessions get summarized, losing critical state.
  • Task drift — without structure, agents wander from the goal.
  • Skipped steps — agents skip review, tests, or cleanup when not enforced.
  • Token waste — using LLM calls for work static analysis does faster.
  • Babysitting — manually orchestrating every phase, every session.

Code does code work. AI does AI work.

Detection uses regex, AST, and static analysis — fast, deterministic, no tokens wasted. Judgment uses LLM calls for synthesis, planning, and review — where reasoning matters. 77% fewer tokens for /drift-detect vs multi-agent approaches.

A command for every phase.

20 plugins. Each is a single, structured pipeline you run with one slash command.

/next-task

Task to production, automated

12-phase workflow: discovers tasks, explores, plans, codes, reviews, ships. One plan approval unlocks autonomous execution through merged PR.

/ship

Branch → merged PR

Commits, pushes, opens the PR, monitors CI, answers reviewer comments, merges, deploys, and cleans up. Auto-detects GitHub Actions, Railway, Vercel.

/prepare-delivery

Pre-ship quality gates

Deslop, simplify, review loop, delivery validation, and docs sync — in order, gated.

/deslop

Kill AI slop before it ships

3-phase detection finds debug statements, placeholders, verbose comments, TODOs, and over-engineering across JS/TS, Python, Rust, Go, Java.

/drift-detect

Documented but not built

AST-based plan-vs-code analysis. JS collectors gather data; one Opus call does semantic matching. Tested on 1,000+ repos.

/perf

Evidence-backed perf work

10-phase methodology: baselines, breaking points, hypothesis generation, profiling, controlled experiments.

/audit-project

Multi-agent code review

Up to 10 specialist agents (security, performance, architecture, DB, API, frontend, backend, DevOps) — iterates until zero open issues.

/agnix

Lint agent configs

399 validation rules (126 auto-fixable) for Skills, Memory, Hooks, MCP, and Plugins across 10+ AI tools. SARIF output for GitHub Code Scanning.

Design principles.

One agent, one job

Same principle as good code: single responsibility. Narrow scope, clear success criteria.

Pipeline with gates

Same principle as DevOps. Each step passes before the next begins. Hooks enforce it — agents cannot skip phases.

Tools do tool work

Regex, AST, and static analysis are deterministic and free. Use them. Save tokens for judgment.
